# Security policy

Use [GitHub private vulnerability reporting](https://github.com/voluzi/aiopelletstove/security/advisories/new)
to report a vulnerability in aiopelletstove. Please include the affected version,
the impact, and steps to reproduce it with synthetic data. Keep the report private
while a fix is being prepared.

Use the [issue tracker](https://github.com/voluzi/aiopelletstove/issues) for ordinary bugs and feature requests.
